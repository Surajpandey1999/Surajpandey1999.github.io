## Rules
- Do not mass-post identical messages.
- Do not automate unsolicited DMs or spam communities.
- Respect each platform and community's rules.
- Add value first; link only when relevant.
- Use the country/platform templates in `campaigns.md`.
- Track links with the UTM convention in `tracking.md`.
